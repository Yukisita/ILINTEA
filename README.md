# StreamPrompter   
ASP.netを用いるwebアプリとする.  
編集モードと、閲覧モードを持つ.  
編集モードは配信裏方、閲覧モードは出演者側がみる前提とする.  
編集モードの画面で編集した内容を、閲覧者画面へリアルタイムで反映する.  
編集モード及び閲覧モードは複数人からできるようにする.  
閲覧モードは、プロンプタで反転する可能性があるため、閲覧画面内で反転などをできるようにする.  
編集モードでは、以下の要素を動的に配置できるようにする.  
- 現在時刻（時計）
- テキストボックス（複数行対応）
- 画像（JPEG、PNGなど一般的なもの）

なるべく外部ライブラリに依存しないこと.  

## 起動

.NET 10 SDKをインストールした環境で、リポジトリのフォルダーから実行します。

起動時に `StreamPrompter.ini` の `[Server]` にある `Port` を読み込みます。初期値は5280です。1～65535の整数を指定し、変更後はサーバーを再起動してください。配布時にもiniファイルを同梱します。以下のURL例は初期値の場合です。

```powershell
dotnet run --project StreamPrompter.csproj
```

- 編集画面: <http://localhost:5280/>
- 閲覧画面: <http://localhost:5280/view/>

起動に成功すると、コンソールにこのPC用のURLと、LAN接続がある場合は別端末用のURLを表示します。ポートが使用中、またはOSから使用を拒否された場合は、原因と使用中のアプリの終了またはiniファイルのポート変更を案内します。通常のコンソールではEnterキーを押すまで案内を表示し、入力がリダイレクトされている場合は待機せず終了します。

時計・複数行テキスト・アラーム・画像・TXT原稿は、追加直後は閲覧者には非表示です。編集画面は左にPreview、右にProgramを並べます。Previewでは非表示・予約待ちを含めたすべての要素を表示し、非表示の要素には枠とラベルを付けます。要素を選んでドラッグで移動、右下のハンドルでサイズ変更できます。Programには閲覧画面と同じ内容だけを表示し、編集用の枠やラベルは出しません。

要素一覧またはPreviewから選んで内容や位置を編集し、設定欄の「表示の操作」から「Programに表示」を押すと閲覧者にも表示します。「Programから隠す」で非表示にしても、Previewでは編集を続けられます。表示中の要素への編集はProgramと閲覧画面にも自動で反映されます。削除ボタンは表示操作の下に分けて置き、削除前に確認を表示します。

FHD画面では、左から要素一覧・要素の設定・Preview／Programの順に表示します。要素を選んだすぐ右隣で内容を編集できます。ブラウザーの表示領域が幅1200px・高さ900px以上なら、20件の要素一覧と全ての設定操作をページのスクロールなしで利用できます。2つのモニターは表示領域に合わせて縮小され、小さい画面では縦にスクロールする配置へ切り替わります。長い原稿はテキスト入力欄の中でスクロールして編集します。

閲覧画面には左右反転・上下反転・全画面表示があります。反転設定はそのブラウザーに保存され、編集画面や別の端末には影響しません。全画面表示はEscキー、または右上にマウスを合わせると現れる終了ボタンで解除できます。

追加ボタンの右にある「画面比率」で16:9・4:3・1:1・3:4・9:16を選べます。Preview・Program・閲覧画面に同じ比率を適用し、配置済みの要素の位置と枠のサイズも比率に合わせて調整します。文字サイズは維持します。比率はサーバー再起動で16:9に戻ります。

「背景色」で画面の色を自由に選べます。Preview・Program・閲覧画面に共通で反映し、文字色や画像は維持します。背景色はサーバー再起動で黒に戻ります。

「＋ アラーム」でアラーム要素を追加し、要素一覧またはPreviewから選んで通知メッセージ・文字色・文字サイズ・位置・表示枠のサイズを編集できます。アラームは合計20要素の範囲で複数追加できます。「表示の操作」で通知日時を指定し、「通知を予約」を押すと、指定時刻に配置した位置へ通知を表示します（音なし）。予約中もPreviewで確認でき、予約変更・解除・即時表示・非表示・削除はほかの要素と同じ設定欄から操作します。

通知は反転・全画面表示にも対応します。編集画面では対象のアラームを選んで「Programから隠す」で通知を止められます。閲覧画面の「通知を止める」は現在通知中のアラームを全端末で非表示にします。将来の通知予約は解除しません。通知を止めてもアラーム要素は一覧に残るため、編集して再び予約できます。

アラームの「残時間の表示」で「予約中も残時間を表示」を選ぶと、予約中は同じ位置に時・分・秒のカウントダウンを表示し、通知時刻にメッセージへ切り替えます。残時間の表示はアラームごとに選べ、初期値は通知時刻まで非表示です。設定欄にも予約の残時間を表示します。

日時は設定するブラウザーの現地時間で入力します。アラームは開いている画面で動作し、スリープやバックグラウンドでの動作制限中は通知が遅れる場合があります。通知時刻を過ぎてから開いた画面にも、非表示にするまで通知を表示します。切断中の画面に対する停止の反映は再接続後になります。

通常の起動でLANからの接続も受け付けます。コンソールに表示する「同じLANの端末」用のURLを開くか、編集画面の「閲覧URLをコピー」を押し、同じLAN内の別端末で開いてください。localhostから編集している場合は、サーバーPCのIPv4アドレスを調べて閲覧URLを作ります。複数の接続がある場合はIPv4ゲートウェイのある接続を優先します。LANアドレスやホスト名で編集画面を開いている場合は、そのアドレスとポートを引き継ぎます。

LAN上のHTTP画面など、ブラウザーがクリップボードへの書き込みを許可しない場合は、URLを表示するので手動でコピーしてください。IPアドレスが変わった場合は、もう一度URLをコピーしてください。

Windowsファイアウォールでは、プライベートネットワークのTCPポート5280を同じサブネットから許可してください。別端末で開けない場合は、両端末が同じLANに接続されているか、Wi-Fiの端末間通信が禁止されていないか確認してください。

## 機能と制約

要素を選択して「表示の操作」内で秒数または分数を指定し、「表示を予約」を押すと、指定時間後に全画面で表示されます（1秒～24時間）。時計・テキスト・画像・TXT原稿に対応し、各要素に1件ずつ予約できます。誤って表示中の要素を消さないよう、予約は非表示の状態で設定します。予約中は残り時間を表示し、「予約を変更」「予約を解除」「予約を解除して表示」を選べます。予約の解除後は非表示のままです。

TXT原稿は予約待ちの間はスクロールせず、「再生」を選んでおけば表示時刻から進みます。表示予約もサーバー再起動でリセットされます。ブラウザーがスリープしていた場合は復帰時に表示状態と再生位置を最新の時刻へ合わせます。

「＋ TXTファイル」でUTF-8の`.txt`ファイルを読み込むと、TXT原稿として配置されます（256KB・50,000文字まで）。要素の設定欄から再生・一時停止・先頭へ戻す操作と速度調整（5～200 px/秒）ができます。非表示の原稿もPreviewで確認できます。原稿は上へスクロールし、末尾で止まります。再生位置と速度は全画面で共有され、途中から開いた閲覧画面も同じ位置に追従します。原稿の文章を書き換えると、先頭に戻って停止します。

- 共有画面は1つです。内容・画像・アラームはメモリー内だけに保持し、サーバー再起動で初期状態に戻ります。
- 要素は合計20個まで、画像は1枚2MBまで（PNG・JPEG・GIF・WebP）です。
- 同じ項目を複数人が編集すると、サーバーが後から受け付けた変更が反映されます。別の項目への変更は上書きしません。
- 接続が切れると編集操作を一時停止します。未反映の変更は自動で再送しません。再接続するとサーバーの最新状態を取得します。
- 時計はサーバー時刻を基準に、各ブラウザーのタイムゾーンで表示します。
- 認証・権限管理は未実装です。閲覧画面は操作を省いた表示用画面であり、アクセス権限の分離はしていません。信頼できるローカル環境での試用を想定しています。

ASP.NET Coreとブラウザー標準機能だけを使用しています。更新通知はServer-Sent Events、編集内容の送信はHTTPで行います。追加のNuGetパッケージ・JavaScriptライブラリ・CDNは使用していません。
