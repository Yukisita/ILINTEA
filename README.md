# ILINTEA（イリンテア）

配信・収録で、スタッフから出演者へ原稿や進行の指示、残り時間をリアルタイムに伝えるブラウザー型プロンプターです。

名前は **Integrated Live Information Terminal Application** の略称です。

## 主な機能

- 原稿・テキスト・時計・画像を自由に配置
- 複数端末でのリアルタイム編集・閲覧
- 編集用のPreviewと、出演者への表示を確認するProgram
- 原稿の自動スクロール、表示予約、残り時間のカウントダウン
- 画面の強調通知、左右・上下反転、全画面表示
- レイアウト・原稿・画像の保存と読み込み
- 日本語・英語の表示切り替え

## 利用について

1台のPCでILINTEAを起動し、同じLAN内の端末からブラウザーで利用します。スタッフは編集画面で内容を準備・操作し、出演者は共有された閲覧URLを開くだけで確認できます。編集・閲覧端末への専用アプリのインストールは不要です。

起動するPCには、.NET 10とASP.NET Core 10のランタイムが必要です（.NET 10 SDKにも含まれます）。
