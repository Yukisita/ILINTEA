# StreamPrompter   
ASP.netを用いるwebアプリとする.  
編集モードと、閲覧モードを持つ.  
編集モードは配信裏方、閲覧モードは出演者側がみる前提とする.  
編集モードの画面で編集した内容を、閲覧者画面へリアルタイムで反映する.  
編集モード及び閲覧モードは複数人からできるようにする.  
閲覧モードは、プロンプタで反転する可能性があるため、閲覧画面内で反転などをできるようにする.  
編集モードでは、以下の要素を動的に配置できるようにする.  
- 現在時刻（時計）
- テキストボックス（複数行対応）
- 画像（JPEG、PNGなど一般的なもの）

なるべく外部ライブラリに依存しないこと.  

## 試作版の起動

.NET 10 SDKをインストールした環境で、リポジトリのフォルダーから実行します。

```powershell
dotnet run --project StreamPrompter.csproj
```

- 編集画面: <http://localhost:5280/>
- 閲覧画面: <http://localhost:5280/view/>

時計・複数行テキスト・画像を追加し、ドラッグで移動、右下のハンドルでサイズ変更できます。右側の設定欄では文字色・文字サイズ・文字揃え・位置・表示／非表示を変更できます。内容は接続している全画面に自動で反映されます。

閲覧画面には左右反転・上下反転・全画面表示があります。反転設定はそのブラウザーに保存され、編集画面や別の端末には影響しません。全画面表示はEscキー、または右上にマウスを合わせると現れる終了ボタンで解除できます。

編集画面の「アラーム」で通知日時とメッセージを設定できます。指定時刻になると、編集・閲覧画面に黄色い枠とメッセージを表示します（音なし）。通知は反転・全画面表示にも対応し、「通知を止める」で全端末の通知を解除できます。設定できるアラームは共有で1件で、再設定すると置き換わります。

日時は設定するブラウザーの現地時間で入力します。アラームは開いている画面で動作し、スリープやバックグラウンドでの動作制限中は通知が遅れる場合があります。通知時刻を過ぎてから開いた画面にも、解除されるまで通知を表示します。切断中の画面に対する解除の反映は再接続後になります。

同じLAN内の別端末から試す場合は、次のように起動し、`localhost`の代わりにサーバーPCのLAN内IPアドレスで接続します。必要に応じてWindowsファイアウォールでポート5280への接続を許可してください。

```powershell
dotnet run --project StreamPrompter.csproj --urls http://0.0.0.0:5280
```

## 試作版の範囲

「＋ TXTファイル」でUTF-8の`.txt`ファイルを読み込むと、TXT原稿として配置されます（256KB・50,000文字まで）。右側の設定欄から再生・一時停止・先頭へ戻す操作と速度調整（5～200 px/秒）ができます。原稿は上へスクロールし、末尾で止まります。再生位置と速度は全画面で共有され、途中から開いた閲覧画面も同じ位置に追従します。原稿の文章を書き換えると、先頭に戻って停止します。

- 共有画面は1つです。内容・画像・アラームはメモリー内だけに保持し、サーバー再起動で初期状態に戻ります。
- 要素は合計20個まで、画像は1枚2MBまで（PNG・JPEG・GIF・WebP）です。
- 同じ項目を複数人が編集すると、サーバーが後から受け付けた変更が反映されます。別の項目への変更は上書きしません。
- 接続が切れると編集操作を一時停止します。未反映の変更は自動で再送しません。再接続するとサーバーの最新状態を取得します。
- 時計はサーバー時刻を基準に、各ブラウザーのタイムゾーンで表示します。
- 認証・権限管理は未実装です。閲覧画面は操作を省いた表示用画面であり、アクセス権限の分離はしていません。信頼できるローカル環境での試用を想定しています。

ASP.NET Coreとブラウザー標準機能だけを使用しています。更新通知はServer-Sent Events、編集内容の送信はHTTPで行います。追加のNuGetパッケージ・JavaScriptライブラリ・CDNは使用していません。
