# StreamPrompter   
ASP.netを用いるwebアプリとする.  
編集モードと、閲覧モードを持つ.  
編集モードは配信裏方、閲覧モードは出演者側が見る前提とする.  
編集モードの画面で編集した内容を、閲覧者画面へリアルタイムで反映する.  
編集モード及び閲覧モードは複数人からできるようにする.  
閲覧モードは、プロンプタで反転する可能性があるため、閲覧画面内で反転などをできるようにする.  
編集モードでは、以下の要素を動的に配置できるようにする.  
- 現在時刻（時計）
- テキストボックス（複数行対応）
- 画像（JPEG、PNGなど一般的なもの）

要素に関しては今後増えていく見込みのため、管理しやすい形式とする.   
なるべく外部ライブラリに依存しないこと.  
当面はローカルネットワーク内での使用を想定しているため、アクセス権等の設定は設けない.
