# ILINTEA（イリンテア）

**Integrated Live Information Terminal Application** の略称です。

配信・収録のスタッフと出演者で画面を共有する、ブラウザー型のプロンプターです。スタッフが編集した原稿・時計・画像・通知を、出演者の閲覧画面へリアルタイムに反映します。

1台のPCでサーバーを起動し、同じLAN内の複数端末から利用できます。編集・閲覧端末への専用アプリのインストールは不要です。

## 主な機能

- テキスト・時計・画像・TXT原稿・アラームの配置
- 複数端末でのリアルタイム編集・閲覧
- Previewで準備し、Programで閲覧者への表示を管理
- 原稿の自動スクロール、表示予約、アラームのカウントダウン
- 画面比率・背景色の変更、閲覧画面の反転・全画面表示
- 日本語・英語の表示切り替え

## 起動

.NET 10 SDKをインストールし、リポジトリのフォルダーで実行します。

```powershell
dotnet run --project ILINTEA.csproj
```

- 編集画面：<http://localhost:5280/>
- 閲覧画面：<http://localhost:5280/view/>

別端末で閲覧する場合は、編集画面の「閲覧URLをコピー」からURLを取得してください。ポートなどの設定は`ILINTEA.ini`で変更できます。

## 画面の強調

編集画面上部の「画面を強調」で、すべての閲覧画面とProgramの枠を5秒間ゆっくり点滅させます。
閲覧側の全画面表示中にも届き、文字の追加や音はありません。
端末でアニメーションを減らす設定が有効な場合は、枠を点滅させずに表示します。
表示中に「強調を解除」を押すと終了します。強調は設定ファイルには保存しません。

## アラーム

「カウント中のメッセージ」「終了後のメッセージ」と終了日時を設定し、
「表示して開始」を押します。Programと閲覧画面にメッセージと残時間を表示し、
終了時刻にメッセージを切り替えます。終了後も残時間は`00:00:00`を表示します。
「終了日時を変更」で再設定でき、「非表示にする」または閲覧画面の
「通知を止める」で解除します。非表示のアラームは通知しません。音は鳴りません。

「指定時間後に表示」は全要素で利用できます。アラームも表示予約中は非表示・無効で、
表示時刻になると、設定した終了日時までの残時間を表示します。
表示前に終了日時を過ぎた場合は、表示時刻に終了後のメッセージと`00:00:00`を表示します。
予約の解除はアラームも解除し、「予約を解除して表示」は終了日時を維持して即時表示します。

設定ファイルには両方のメッセージを保存します。復元後のアラームは非表示・無効です。
設定ファイルはILINTEAの形式バージョン2に対応しています。

## 利用上の注意

- 画面の内容はメモリー内だけに保持され、サーバーを停止・再起動すると失われます。
- 認証・権限管理は未実装です。信頼できるLAN内で利用し、インターネットへ直接公開しないでください。
